# 💜 sobre o projeto

o **sistema de gerenciamento eleitoral** foi desenvolvido para a **atividade saep – desenvolvimento de crud em php**, da escola **senai a. jacob lafer**.

o projeto consiste em uma aplicação web desenvolvida com **php e mysql**, destinada ao gerenciamento de informações relacionadas a **eleitores e candidatos**.

a aplicação utiliza o conceito de **crud**, permitindo realizar quatro operações principais:

<div align="center">

| operação | significado | função |
|:---:|:---:|:---|
| 🟣 **create** | criar | cadastrar registros |
| 🔵 **read** | ler | consultar registros |
| 🟡 **update** | atualizar | editar registros |
| 🔴 **delete** | excluir | remover registros |

</div>
